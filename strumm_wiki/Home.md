## ✦ Overview

Strumm is built to prove that free software can have premium design and robust features. By leveraging modern frameworks, Strumm provides real-time media session synchronization, dynamically synced lyrics, unrestricted downloads, smart LLM-powered recommendations, and optional video podcast playback.

### Key Milestones
* **Monorepo Architecture**: Clean separation of shared types, configuration, frontend applications, and API microservices.
* **Unified Player State**: A single, persistent audio and video player state managed via Zustand.
* **Smart Curation**: Integration with Groq API for intelligent playlist flow based on user moods.
* **Optional Video Podcasts**: Seamlessly parses video enclosures from RSS feeds and switches rendering contexts dynamically.
